# 감자 주식회사 (Potato Inc.) — 게임 기획서

> "감자로 시작해서 감자로 끝난다. 사실 안 끝난다."

---

## 0. 한 줄 요약

노점 리어카 하나로 시작해 감자튀김·매시드 포테이토·뇨끼까지 수십 가지 감자 요리를 만들고,
동네 → 도시 → 전국 → 해외로 분점을 늘려 가는 **사이드뷰 단면 픽셀 타이쿤**.
직접 굴리는 재미(병목 해결, 러시 타임, 특별 주문)와 켜두는 재미(매니저 자동화, 오프라인 수익)를 섞고,
엔딩 뒤에도 회차(브랜드 리부트), 무한 해외 시장, 도감 수집으로 계속 즐길 수 있게 만든다.

## 1. 확정된 방향 (역질문 답변)

| 항목 | 결정 |
|---|---|
| 플랫폼 | 웹 브라우저 (PC + 모바일 모두 플레이 가능, 모바일 세로 화면 우선 고려) |
| 플레이 방식 | 능동 운영 + 방치 혼합 |
| 시점 | 측면(사이드뷰) 단면. 건물을 잘라 층별로 보여준다 |
| 엔드게임 | 프레스티지(회차), 무한 해외 진출, 도전 과제·도감 수집 |
| 아트 | 픽셀 아트, 하지만 레트로 흉내 금지 (CRT·스캔라인·8비트 팔레트 X) |
| 캐릭터 톤 | 살짝 병맛. 무표정·담백. 볼터치·과한 귀여움 X, 과하게 웃기려는 개그 X |
| 이펙트 | patch-gg/pixelfx 코어 엔진 사용, 샘플 이펙트는 쓰지 않고 전부 자체 제작 |

## 2. 디자인 원칙

1. **5분마다 뭔가 새롭다.** 초반엔 3~5분, 중반엔 15~30분, 후반엔 1시간 안에 새 메뉴·새 시스템·새 지역 중 하나는 열린다.
2. **병목이 곧 게임이다.** 감자 공급 → 주방 라인 → 덤웨이터 → 카운터 → 손님. 어디가 막혔는지 눈에 보이고, 고치면 바로 숫자가 오른다.
3. **직접 하면 이득, 안 해도 손해는 아니다.** 탭·이벤트 대응은 가속이고, 방치해도 진행은 된다.
4. **새 시스템은 하나씩.** 챕터마다 시스템 하나를 열어서 설명 없이도 배울 수 있게 한다.
5. **유머는 대사와 상황에서.** 캐릭터 생김새는 심플하게. 웃음은 무표정한 한 줄 리뷰, 진지한 척하는 비서, 이상하게 집요한 경쟁사에서 나온다.

## 3. 아트 디렉션

### 3.1 화면 구성
- 내부 픽셀 해상도: 가로 **192px** 고정, 세로는 화면 비율에 맞춰 가변. 정수배 확대(`image-rendering: pixelated`).
- 건물 단면이 화면 중앙. 위로 갈수록 주방 층, 1층은 홀, 지하는 창고. 위아래 드래그(스와이프)로 스크롤.
- UI(숫자·버튼·패널)는 HTML 오버레이로 선명하게. 한글 픽셀 폰트 **Galmuri**(OFL) 사용.

### 3.2 레트로 아닌 픽셀
- 팔레트 제한 없음. 채도 낮은 웜톤 베이스 + 포인트 컬러(감자 노랑, 케첩 빨강, 주방 스틸 블루).
- pixelfx의 **light 버퍼**로 실제 조명 느낌: 튀김기 불빛, 창문 햇살, 밤 시간대 간판 조명.
- 부드러운 카메라 이동, 패널 슬라이드 애니메이션, 숫자 롤링. 화면 흔들림은 큰 이벤트에서만 약하게.
- 낮/저녁/밤 시간 흐름에 따라 창밖 하늘색과 실내 조명이 바뀐다.

### 3.3 캐릭터
- 크기: 직원·손님 약 10×16px. 단순한 실루엣, 점 두 개 눈, 일자 입. **볼터치 없음.**
- 표정은 거의 안 바뀐다. 감정은 말풍선 아이콘(…, !, 감자 아이콘)과 한 줄 대사로.
- 병맛 포인트는 "설정"으로만:
  - **박감자 사장**: 머리 모양이 묘하게 감자 같은 중년. 콧수염, 작은 넥타이. 늘 진지하다.
  - **김비서**: 안경, 클립보드. 감정 없는 보고 담당. "사장님, 감자가 감자입니다."
  - **고구마 그룹 회장 (고회장)**: 보라색 정장. 쓸데없이 경쟁심이 강하다.
  - 손님: 직장인, 학생, 할머니, 관광객, 미식 평론가(외눈 안경), 고구마 그룹 스파이(선글라스+트렌치코트, 숨기는 척만 함) 등.
- 대사 예시 (적정선 유지):
  - "바삭하다. 그게 다다."
  - "어제도 왔다. 내일도 올 것 같다."
  - "감자탕을 시켰는데 감자가 없다. 메뉴판에 그렇게 써 있긴 했다."
  - 김비서: "오늘 매출은 어제보다 높습니다. 어제는 오늘보다 낮았습니다."

## 4. 핵심 루프

```
[감자 공급] → [창고 B1] → [주방 라인 2F~] → [덤웨이터] → [카운터 1F] → [손님] → 돈
      ↑                                                                  │
      └──────────── 업그레이드 / 매니저 / 신메뉴 / 분점 ←─────────────────┘
```

### 4.1 분점 하나의 구조 (단면)
| 층 | 시설 | 역할 |
|---|---|---|
| 옥상 | 간판 | 브랜드 레벨, 러시 타임 표시. 확장하면 광고판 |
| 2F~ | 주방 라인 | 층마다 메뉴 하나. 손질 → 조리 → 마무리 3개 스테이션 |
| 1F | 홀 & 카운터 | 손님 입장·대기·주문·식사. 좌석 수, 계산대 수 |
| B1 | 창고 | 감자 보관량, 입고 속도 |
| 우측 | 덤웨이터 | 창고↔주방↔카운터 운반. 용량·속도 |

### 4.2 생산 규칙
- 라인 생산량 = 세 스테이션 중 **가장 느린 곳** 기준 (병목이 눈에 보이도록 느린 스테이션에 빨간 표시).
- 메뉴 1개 = 감자 N개 소모. 창고가 비면 라인 정지.
- 완성품은 라인 트레이에 쌓이고, 덤웨이터가 주기적으로 걷어 카운터로 운반.
- 손님은 수요율에 따라 입장해 진열된 메뉴 중 하나를 고른다. 재고 없으면 잠깐 기다리다 떠난다(만족도 하락).

### 4.3 직접 하다가 자동화하기 (v0.2 개편)
게임은 지하 창고와 1층 가게 하나로 시작한다. 1층에 첫 주방(찐감자)과 카운터가 함께 있다.
플레이어는 **박감자 사장**을 직접 움직인다.

| 일 | 처음 (사장이 직접) | 자동화 |
|---|---|---|
| 감자 운반 (지하 → 주방 감자 통) | 창고나 빈 주방을 누르면 사장이 계단으로 내려가 감자를 들고 올라온다 | 창고에 **운반 매니저** |
| 조리 | 주방을 누르면 사장이 가서 조리한다. 계속 누르면 빨리 익는다 | 주방에 **조리 매니저** |
| 음식 내리기 (2층 이상 → 1층 카운터) | 덤웨이터를 눌러 한 번씩 보낸다 | **덤웨이터 매니저** |
| 판매 | 카운터에서 자동 | **카운터 매니저**는 보너스 |

- 1층 주방의 음식은 바로 카운터에 진열된다. 2층부터는 덤웨이터가 필요하다.
- 본점 밖 분점은 기본 직원이 35% 속도로 돌린다. 매니저를 두면 제 속도가 난다.
- 오프라인 수익은 자동화된 비율만큼(70%), 기본 2시간, 특허로 최대 24시간.

### 4.4 챕터 1~3 (튜토리얼 흐름)
1. **첫 가게:** 감자 옮기기 → 찐감자 20개 → 매니저 고용 → 조리 매니저 배치
2. **운반:** 운반 매니저 배치 → 찐감자 라인 Lv10 → 누적 100만원
3. **2층:** 증축 → 감자튀김 라인 → 덤웨이터 10번 직접 운행 → 덤웨이터 매니저 배치

### 4.5 대사 톤 (v0.2)
억지 개그를 빼고, 김비서가 시스템을 설명하는 담백한 대사로 바꿨다. 메뉴 설명은 그대로 둔다.

### 4.6 효과음
Kenney "Interface Sounds"(CC0)에서 20개를 골라 쓴다 (`src/sfx`). 탭, 감자 집기/붓기, 판매, 업그레이드, 마일스톤, 목표, 업적, 덤웨이터 등. 설정에서 끌 수 있다.

### 5.2 연구소 (Ch4~): 레시피 조합
- 카드 3장 조합: **재료**(감자 품종) + **조리법**(튀기기/삶기/굽기/으깨기/부치기/얼리기) + **곁들임**(치즈/버터/케첩/트러플/우유/설탕).
- 정답 조합이면 새 메뉴 발견. 틀리면 무표정한 결과 카드: "그냥 생감자다.", "감자를 얼렸다. 차갑다."
- 틀린 조합도 "실패작 도감"에 기록 → 수집 요소.
- 힌트는 손님 대사와 김비서 보고서에 숨겨둔다.

### 5.4 감자 시장
- 감자 시세가 시간에 따라 오르내린다 (그래프 표시). 쌀 때 사두면 이득.
- 이벤트 "감자 파동"(시세 3배), "풍년"(시세 절반).
- 농장을 늘리면 시장 의존도가 줄어든다 → 중반 이후 전략 선택.

### 5.5 매니저 (직원 수집)
- 등급: 일반 / 숙련 / 장인 / 전설.
- 특성 예시 (담백한 병맛):
  - "말이 없다" — 효과 없음. 그냥 말이 없다.
  - "칼질 장인" — 손질 속도 +30%
  - "기름 냄새 좋아함" — 튀김 라인 +20%
  - "고구마 그룹 출신" — 속도 +40%, 가끔 고구마를 섞는다(판매가 -5%)
  - "아침형 인간" — 점심 러시 +50%, 저녁엔 졸림
- 헤드헌팅: 돈 또는 명성으로 뽑기 없이 **후보 3명 중 선택** (확률 뽑기 X).

| 주택가 | 꾸준함, 수프·조림 선호 |
| 역세권 | 손님 많고 회전 빠름, 좌석 적음 |
| 공항 | 모든 가격 ×1.5, 임대료 높음 |

분점은 각자 독립적으로 돌아가고, 지금 보고 있지 않은 분점은 수치로 계산한다.
본사 화면(지도)에서 분점 전체 매출을 한눈에 확인.

### 5.7 이벤트
| 종류 | 예시 | 플레이어 대응 |
|---|---|---|
| 정기 | 점심·저녁 러시 | 재고 비축 |
| 특별 주문 | "단체 주문: 감자튀김 50개, 90초" | 받거나 거절, 성공 시 보너스 |
| 방문객 | 미식 평론가 (리뷰 별점에 따라 명성 변화) | 대기시간 짧게 유지 |
| 시장 | 감자 파동, 풍년 | 사재기 / 절약 |
| 사고 | 튀김기 과열, 위생 점검 | 탭해서 해결 |
| 경쟁 | 고구마 그룹 맞은편 개업 | 할인 이벤트 or 신메뉴로 대응 |
| 운 | 인플루언서 방문 (10분간 수요 5배) | 놓치지 말 것 |

## 6. 스토리 & 챕터 (메인 루트)

각 챕터 = 목표 3~5개 + 새 시스템 1개 + 컷신(대화 몇 줄).

> v0.2에서 챕터가 11개로 늘었다 (앞쪽 1~3이 튜토리얼, 아래 표의 2~10이 4~11로 밀림).

| 챕터 | 제목 | 새 시스템 | 대표 목표 | 예상 시간 |
|---|---|---|---|---|
| 1 | 리어카 | 기본 생산·판매·업그레이드 | 첫 1만원 | 15분 |
| 2 | 첫 가게 | 층 추가, 덤웨이터 | 3개 메뉴 운영 | 40분 |
| 3 | 매니저 | 매니저 고용, 오프라인 수익 | 매니저 3명 | 1.5시간 |
| 4 | 연구소 | 레시피 조합 | 신메뉴 3개 발견 | 2시간 |
| 5 | 분점 | 두 번째 가게, 상권 | 분점 3개 | 3시간 |
| 6 | 고구마의 습격 | 경쟁사, 특별 주문 | 고구마 그룹 점유율 역전 | 4시간 |

→ 본편 약 **35시간**. 회차 보너스를 쓰면 더 빨라지지만, 엔딩 후 콘텐츠가 열린다.

### 엔딩
세계 감자 엑스포에서 박감자 사장이 연설한다. "감자는… 감자입니다." 박수.
고회장도 몰래 박수친다. 크레딧 후, 김비서: "사장님, 화성에 감자 농장 부지가 나왔습니다."

## 7. 엔딩 이후 (포스트 게임)

### 7.1 브랜드 리부트 (회차, Ch8에서 해금)
- 회사를 매각하고 처음부터. 누적 매출에 따라 **황금감자** 획득.
- 황금감자로 **특허 트리** 영구 해금 (40개 노드):
  - 생산 계열: 모든 라인 속도 +, 시작 자금 +, 처음부터 매니저 1명
  - 경영 계열: 오프라인 시간 +, 분점 개설 비용 -
  - 연구 계열: 레시피 힌트, 실패작 확률 -
  - 특수: 황금감자 품종, 자동 특별 주문 수락
- **회차 규칙(선택)**: 리부트 시 핸디캡을 고르면 황금감자 추가.
  - "튀김기 금지" (튀김 메뉴 없음) ×1.5
  - "감자 시세 2배" ×1.3
  - "매니저 파업" (매니저 없음) ×2

### 7.2 무한 해외 진출 (신시장)
- 엔딩 후 지도 끝에 "신시장"이 계속 생성된다 (절차 생성 국가, 무작위 선호 메뉴·상권·규칙).
- 시장 단계가 오를수록 수요·가격이 커지고, 단계별 기록이 남는다.
- 화성 농장, 달 분점 같은 농담성 시장도 섞인다 (중력이 약해 감자튀김이 떠다님 — 효과는 진지하게).

### 7.3 수집 & 도전 과제
| 도감 | 개수 |
|---|---|
| 레시피 | 30 + 숨은 메뉴 + 해외 한정 |
| 실패작 | 40+ |
| 품종 | 10 |
| 손님 | 20종 |
| 매니저 | 40명 |
| 손님 리뷰 | 100+ 문장 |
| 업적 | 120+ (일부 숨김) |

업적 보상은 영구 소폭 버프 (예: 업적 10개마다 매출 +1%) → 수집이 곧 성장.

## 8. 경제 설계

- 통화: **원(₩)**. 큰 숫자는 한국식 단위 (만, 억, 조, 경, 해, 자, 양, 구, 간…). 이후는 알파벳 단위.
- 업그레이드 비용: `base × 1.15^level` (스테이션), `base × 1.25^level` (덤웨이터·카운터)
- 생산량: 레벨에 선형 + **마일스톤 배수** (Lv 10, 25, 50, 100, 200…에서 ×2). 마일스톤마다 이펙트.
- 메뉴 가격: 메뉴마다 기본 가격 × 지역 배수 × 명성 배수.
- 수요: `기본 손님/초 × 명성 × 상권 × 시간대 × 가격 탄력성`
- 가격 조절(0.5×~2.0×): 비싸면 손님 감소, 싸면 증가. 최적점이 메뉴·상권마다 다르다.
- 명성(별점 1~5): 대기 시간·품절·평론가 리뷰로 변동. 수요 배수.
- 밸런스 목표: 각 업그레이드가 "구매 가능해지기까지" 30초~3분 유지.

## 9. UI / UX (모바일 우선)

```
┌──────────────────────┐
│ ₩ 1.23억   ★4.2  ⏱점심│ ← 상단 HUD (돈, 명성, 시간대)
│ [목표: 감자튀김 100개] │ ← 현재 챕터 목표 (탭하면 상세)
├──────────────────────┤
│                      │
│   건물 단면 (스크롤)    │ ← 드래그로 위아래, 층 탭 → 업그레이드 시트
│                      │
├──────────────────────┤
│ 🏪가게 🔬연구 🗺지도 📖도감 ⚙│ ← 하단 탭바
└──────────────────────┘
```
- 층을 탭하면 아래에서 **바텀 시트**가 올라온다 (스테이션별 레벨·업그레이드·매니저).
- 구매 버튼 길게 누르면 연속 구매. ×1 / ×10 / ×최대 토글.
- 화면 크기: 360×640 이상 모바일 대응, PC에선 중앙 세로 레이아웃 + 넓은 화면이면 옆에 패널.
- safe-area 대응, 홈 화면 추가(PWA 매니페스트).
- 진동(가능한 기기)은 마일스톤·이벤트에서만 짧게.

## 10. 기술 설계

| 항목 | 선택 |
|---|---|
| 언어/빌드 | TypeScript + Vite |
| UI | Preact (HTML 오버레이) |
| 렌더 | Canvas 2D, pixelfx 프레임 (color + light 버퍼) → composite → putImageData |
| 스프라이트 | 이미지 파일 없이 코드(문자열 픽셀맵)로 그린다. pixelfx `p.sprite` 사용 |
| 시뮬레이션 | 고정 틱(10Hz) 경제 시뮬 + 매 프레임 연출. 안 보는 분점은 수치 근사 |
| 저장 | localStorage (try/catch), 10초마다 + 탭 숨김 시 자동 저장, 내보내기/불러오기 문자열 |
| 오프라인 | 마지막 저장 시각 기준, 매니저 있는 라인만 근사 계산 |
| 데이터 | 메뉴·스테이션·챕터·이벤트·업적 등 전부 `src/data/*.ts` 데이터 주도 |

### 폴더 구조
```
src/
  vendor/pixelfx/core   # pixelfx 엔진 (MIT)
  fx/                   # 자체 제작 이펙트
  art/                  # 코드 스프라이트 (캐릭터, 시설, 음식)
  data/                 # 메뉴, 챕터, 업적, 매니저, 품종, 지역
  sim/                  # 경제·생산·손님·이벤트 시뮬레이션
  render/               # 건물 단면 렌더러, 카메라
  ui/                   # Preact 컴포넌트 (HUD, 시트, 탭)
  save/                 # 저장/불러오기/오프라인
```
