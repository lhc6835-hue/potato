# 샌드백 타이쿤

판타지 세계의 샌드백을 두드려 골드를 벌고, 무기를 모으고, 동료를 고용하고, 환생을 거듭하며 끝없는 심연까지 내려가는 픽셀 방치형 타이쿤.
브라우저에서 모바일(세로)과 PC 모두 플레이할 수 있다.

## 규모

- **공격 방식 9종**: 무기 종류마다 조작이 다르다
  | 방식 | 무기 | 조작 |
  |---|---|---|
  | 연타 | 권갑 | 탭할 때마다 주먹이 날아간다. 10연타마다 강타 |
  | 베기 | 도검 | 샌드백을 가로질러 스와이프. 빠를수록 세다 |
  | 사격 | 총기 | 누르고 있으면 조준점으로 연사. 과열 게이지 |
  | 강타 | 둔기 | 꾹 눌러 힘을 모았다가 놓기. 퍼펙트 타이밍 존재 |
  | 찌르기 | 창 | 줄어드는 링이 목표 링과 겹칠 때 탭 (퍼펙트·굿·빗나감, 연속 보너스) |
  | 투척 | 단검·도끼·부메랑·폭탄 | 샌드백 쪽으로 튕기듯 던지기. 꽂힌 무기는 남는다 |
  | 궁술 | 활 | 뒤로 당겼다 놓기. 궤적 미리보기, 머리를 맞히면 헤드샷 |
  | 주문 | 지팡이·마도서 | 룬 그리기: 원 = 노바, 지그재그 = 낙뢰, 직선 = 마력탄, 탭 = 마법탄 (마나) |
  | 휘두르기 | 플레일·사슬낫 | 사슬 물리. 손잡이를 끌고 다니며 빙빙 돌려 후려친다 |
- **무기 61종** (일반 ~ 신화 6등급, 8속성), 레벨업·강화(+10)·특수 능력
- **샌드백 37종**, 지역 7곳 + 끝없는 심연, 지역 보스·정예 샌드백(제한 시간), 황금 샌드백
- **동료 8명**이 양옆에서 자동으로 때린다 (오프라인 보상)
- 시설 8종, 환생(영혼) + 영혼 각인 10종, 보석 상점(보물 상자 뽑기), 업적 44개, 샌드백 도감
- 피버 타임, 콤보, 보물 고블린, 보물 상자, 속성 상태이상(화상·빙결·감전·중독·심판·저주)

## 만든 방식

- 그림은 전부 코드로 그렸다. 샌드백은 SDF(부호 거리 함수)로 모양을 정의하고 경사로 법선을 구해 단계 램프로 입체 음영을 칠한다.
  맞으면 진자처럼 흔들리고, 찌그러지고(스쿼시), 맞은 자리가 움푹 들어가며(덴트), 체력이 줄면 금이 간다.
- 이펙트는 [patch-gg/pixelfx](https://github.com/patch-gg/pixelfx) 스킬의 가이드라인(색 버퍼 + 빛 버퍼, 단계 램프, 히어로 프레임,
  히트스톱, 예비 동작 → 타격 → 회복)에 맞춰 이 게임을 위해 새로 만들었다 (`src/fx`). 라이브러리의 샘플 이펙트는 쓰지 않고,
  엔진 코어(MIT, `src/vendor/pixelfx`)만 쓴다. 각 이펙트는 pixelfx 형식(`meta` + `create`)이라 pixelfx 도구로 렌더·검사할 수 있다.
- 효과음·배경음은 WebAudio로 합성한다 (에셋 파일 없음). 폰트: Galmuri (OFL).

## 실행

```bash
npm install
npm run dev
```

빌드: `npm run build` → `dist/`. 파일 하나로: `npm run build:single` → `dist-single/index.html`.

## 개발 도구

```bash
npx tsx tools/look-bags.ts       # 샌드백 전체를 PNG로 (records/bags.png)
npx tsx tools/look-weapons.ts    # 무기 전체
npx tsx tools/look-regions.ts    # 지역 배경
npx tsx tools/bot.ts 24          # 밸런스 봇: 24시간 플레이 시뮬레이션 (환생 포함)
tools/fxlook.sh <pixelfx 경로> hit/slam --zoom 3   # 이펙트를 pixelfx로 렌더·검사
node tools/play.cjs swipe out.png   # 브라우저로 조작해 스크린샷 (dev 서버 필요)
```

## 폴더

```
src/
  vendor/pixelfx/core   pixelfx 엔진 코어 (MIT)
  fx/                   게임 전용 이펙트 (pixelfx 형식)
  art/weapons.ts        무기 그림
  data/                 속성, 공격 방식, 무기, 샌드백·지역, 동료·시설·각인·업적
  engine/               화면, 한글 픽셀 글자, 소리 합성, 숫자 표기
  game/                 샌드백(SDF·물리), 세계(타격 처리), 조작 9종, 동료, 배경, 경제·저장, 행동
  ui/                   Preact UI
```
